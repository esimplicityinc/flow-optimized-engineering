# The Playbook

Institutions cover the predictable.

Life is not predictable.

So you need a playbook: how we think when the mechanism doesn’t answer.

## The playbook rules

### Speed

Speed isn’t the enemy.

Surprise is.

Go fast with visibility. Never fast with hope.

### Work movement

Every change should have a trail:

**Intent → Change → Evidence → Outcome**

If “why” can’t be answered, the system is accruing meaning-debt.

### Risk

Don’t avoid risk. Make it visible, bounded, and recoverable.

### Decisions

Evidence over opinion.

Experiments over debates.

Reversible decisions quickly.

Irreversible decisions carefully.

### Learning

Blameless postmortems that produce code: tests, policies, alerts, and automation.

If it stays in a doc, it will be forgotten.
