# Common Pitfalls

You don’t fail FOE because the ideas are wrong.

You fail FOE because predictable human incentives quietly sabotage it.

## 1) Tools ≠ discipline

Having Kubernetes is not operating cloud-native.

Having CI is not doing continuous delivery.

If behavior didn’t change, capability didn’t change.

## 2) Exception erosion

“Just this once” is how standards die.

Prefer technical enforcement.

If you can bypass it, you will.

## 3) Celebrating heroics

Rewarding firefighters creates fires.

Make prevention visible.

Promote institution-builders.

## 4) Measuring activity

Activity metrics create gaming.

Outcome metrics create learning.

Choose wisely.

## 5) Treating transformation as a project

Projects end.

Capability building doesn’t.

If you stop investing, entropy wins.
