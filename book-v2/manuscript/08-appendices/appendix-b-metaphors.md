# Appendix B: Key Metaphors (Quick)

| Metaphor | Use it when you need to explain… |
|---|---|
| **Gauges** | Instrumentation enables speed. |
| **Cockpit** | Tools offload cognition so humans can judge. |
| **Operating envelope** | Boundaries create confidence; without limits you freeze. |
| **Pets vs cattle** | Replace instead of repair; standardize for automation. |
| **Receipts** | Automation generates audit evidence as a byproduct. |
| **J-curve** | Transformation dips before it climbs. |
