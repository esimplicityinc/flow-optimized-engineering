# Appendix C: Anti-Patterns

**Tool worship:** buying tools instead of adopting disciplines.

**Phase skipping:** adopting AI speed without Phase 3 foundations.

**Hero dependence:** the same names save every incident.

**Activity metrics:** measuring motion instead of outcomes.

**Exception erosion:** “just this once” slowly kills standards.

**Improvement theater:** retrospectives without automation or follow-through.

**Premature victory:** declaring “we’re done” before behavior holds under pressure.
