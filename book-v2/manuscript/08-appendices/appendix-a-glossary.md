# Appendix A: Glossary (Short)

**Agentic coding**: AI systems that act (implement, test, open PRs), not just suggest.

**Alignment**: Does the change match intent and real needs?

**Blast radius**: How much damage a failure can cause.

**CI gate**: Automated checks that must pass before merge.

**Coherence**: The system stays interpretable as it changes (intent → evidence → outcome).

**Confidence**: Calibrated belief you can act safely because risk is bounded and recovery is real.

**DORA metrics**: Deployment frequency, lead time, change failure rate, MTTR.

**Fast feedback**: Truth arrives before context is lost.

**GitOps**: Git is the source of truth; automation reconciles actual state to declared state.

**Guardrails**: Constraints that prevent catastrophe while preserving speed.

**Institution**: A lightweight mechanism that makes a behavior default (not a memo).

**J-curve**: Transformation gets worse before it gets better.

**Maturity**: Predictability of outcomes, not sophistication of tooling.

**Operating envelope**: Defined safe boundaries that enable confident action.

**Phase 2**: Modern tools, old disciplines.

**Phase 3**: Consistent, enforced, repeatable, measurable operations.

**Verification**: Proof the system behaves as intended.

**Vibe coding**: Output-first delivery without evidence; speed by caring less.
