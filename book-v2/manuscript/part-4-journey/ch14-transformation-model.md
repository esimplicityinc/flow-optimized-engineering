# The Transformation Model

If you can’t locate yourself on the map, every “strategy” is just motion.

This part is orientation, not philosophy.

Where are you? Where are you trying to go? What can’t be skipped?

## The six phases

1. **Phase 0: On-Prem** — manual, tribal, pets.
2. **Phase 1: Lift & Shift** — cloud location, old operating model.
3. **Phase 2: Awkward Middle** — modern tools, old disciplines.
4. **Phase 3: Cloud Native Infrastructure** — consistent, enforced, repeatable, measurable.
5. **Phase 4: Agentic Coding** — code abundance changes the bottleneck.
6. **Phase 5: Cloud Native Code** — standardized, governed, composable code.

Phases are not badges.

They’re operating realities.

## The dependency

Phase 5 depends on Phase 3.

If your infrastructure is not consistent, enforced, repeatable, and measurable, AI doesn’t create leverage.

AI creates entropy.

## The honesty test

Ask questions with yes/no answers:

- Do people ever change production outside the declared source of truth?
- Do “exceptions” exist as a standing category?
- Can anyone run operations without a specific hero?
- Do metrics trigger automation—or meetings?

If you’re flinching, that’s your location.
