# Institution Anatomy Box

## Description
A structured box showing the six components of a well-designed institution.

## Visual Elements
A rectangular box/card with header "INSTITUTION" and six labeled sections:

1. **PURPOSE**: Why does this exist?
2. **MECHANISM**: How does it work?
3. **TRIGGER**: When does it activate?
4. **ENFORCEMENT**: What happens on violation?
5. **OWNER**: Who is accountable?
6. **MEASURE**: How do we know it's working?

## Context
Used in: `docs/docs/implementation/building-institutions.md`

This shows the anatomy of an effective FOE institution, highlighting that each needs all six components to be sustainable.
