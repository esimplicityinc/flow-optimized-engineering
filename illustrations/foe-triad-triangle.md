# FOE Triad Triangle

## Description
A triangle diagram showing the interconnection of People, Process, and Technology.

## Visual Elements
- Equilateral triangle with vertices labeled:
  - Top: **People**
  - Bottom-left: **Process**
  - Bottom-right: **Technology**
- Connecting lines between all three vertices (showing interdependence)
- Center of triangle could contain "FOE" or a flow icon
- Use brand colors from the site (deep blue #1e40af as primary)

## Context
Used in: `docs/docs/triad/overview.md`

This illustrates that FOE transformation requires coordinated change across three interconnected dimensions. Technology alone fails without process and people changes.

## ASCII Reference
```
        People
         /\
        /  \
       /    \
      /      \
     /________\
 Process ---- Technology
```

## Suggested Style
- Clean, modern line art or filled shapes
- Consider subtle gradient or shadow for depth
- Should work in both light and dark mode (use colors with good contrast)
