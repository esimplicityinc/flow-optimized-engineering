# Phase 2 vs Phase 3 Consistency

## Description
A comparison visual showing the difference in consistency between Phase 2 and Phase 3 organizations.

## Visual Elements
Two horizontal bar charts or progress indicators:

**Phase 2 Consistency:**
- Bar showing ~50% "Standard" (solid fill)
- Bar showing ~50% "Exceptions" (striped or different color)
- Label: "Phase 2 Consistency"

**Phase 3 Consistency:**
- Bar showing 100% "Standard" (solid fill, green)
- "Exceptions: (none; standard evolves)" as text below
- Label: "Phase 3 Consistency"

## Context
Used in: `docs/docs/transformation-model/why-phase-3-is-the-bottleneck.md`

This illustrates the key difference: Phase 3 requires 100% consistency with no exceptions. Standards evolve rather than having carve-outs.
