# Cognitive Triangle (Three Optimizations)

## Description
A triangle diagram showing the three FOE optimizations and their interactions.

## Visual Elements
- Equilateral triangle with vertices labeled:
  - Top: **Understanding** (cyan #0891b2)
  - Bottom-left: **Confidence** (green #059669)
  - Bottom-right: **Fast Feedback** (purple #7c3aed)
- Bidirectional arrows between all vertices showing mutual reinforcement
- "FOE" in the center
- Each vertex could have a small icon:
  - Understanding: magnifying glass or eye
  - Confidence: shield with checkmark
  - Fast Feedback: lightning bolt or circular arrows

## Context
Used in: `docs/docs/principles/cognitive-triangle.md`

This illustrates how the three optimizations form a closed system where each enables the others. When one collapses, it degrades the others.
