# Research

This section contains Scout reports that survey the agentic coding landscape to identify trends, tools, and patterns relevant to Flow Optimized Engineering.

## Scout Reports

Scout is an automated research workflow that crawls multiple sources to identify emerging trends in agentic coding:

- **Reddit** - r/ClaudeAI, r/LocalLLaMA, r/programming, r/MachineLearning
- **YouTube** - Tutorials, demos, and conference talks
- **GitHub** - Trending repos, releases, and discussions
- **skills.sh** - Reusable AI coding skills catalog
- **Web** - Hacker News, arXiv, company blogs

## Report Structure

Each Scout report includes:

- **Key Trends** - Cross-source validated patterns with signal strength
- **Method Candidates** - Practices ready for FOE documentation
- **Experiment Candidates** - Opportunities for formal experiments
- **Skills Analysis** - Reusable skills with FOE alignment notes
- **Suggested Actions** - Prioritized next steps
