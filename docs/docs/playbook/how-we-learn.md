# How We Learn (Without Blame)

<span class="badge badge--success">Engineers</span> <span class="badge badge--secondary">Leadership</span>

> **"Learning requires feedback before damage becomes irreversible."**

## Our Default Behaviors

- **Small changes**  -  mistakes are contained, lessons are clear
- **Early signals**  -  we know something's wrong before customers do
- **Clear rollback paths**  -  every change can be undone

## What This Enables

| Behavior | Result |
|----------|--------|
| Small changes | Faster iteration |
| Early signals | Less fear |
| Clear rollback | Fewer heroic recoveries |

## How Blame Kills Learning

When failure triggers punishment:

- People hide problems
- Risk goes underground
- Near-misses go unreported
- The same mistakes repeat

**Blame feels like accountability. It's actually the opposite.**

## What Learning Looks Like Here

- Incidents are analyzed, not prosecuted
- Near-misses are reported and valued
- "What did we learn?" is a real question, not a ritual
- Improvements are implemented, not just documented

## What This Looks Like in Practice

**After something goes wrong:**

1. What happened? (facts, not fault)
2. How did we find out? (detection)
3. How did we respond? (containment)
4. What would have caught this earlier? (improvement)
5. What changes do we make? (action)

**What we don't ask:** Who screwed up?

## Maps To

**Fast Feedback Optimization**  -  Feedback loops that teach before they punish.
