# FOE Bookshelf

The intellectual foundations of Flow Optimized Engineering draw from decades of research and practice across multiple disciplines. This curated collection represents the core references that shape FOE's approach to **fast feedback**, **high confidence**, and **sustained flow**.

These aren't just "recommended reading"—they're the building blocks. Each resource maps directly to FOE principles and practices.

## How to Use This Bookshelf

### For Learning FOE Foundations

Start with these if you want to understand *why* FOE works:

1. **Accelerate** — The research foundation for everything DORA-related
2. **Thinking in Systems** — Understanding feedback loops and leverage points
3. **The Principles of Product Development Flow** — The mathematics of flow

### For Implementing FOE

These are practical guides for *how* to apply FOE:

1. **The DevOps Handbook** — Practices and operating models
2. **Continuous Delivery** — The deployment pipeline discipline
3. **Team Topologies** — Org design for fast flow
4. **Site Reliability Engineering** — Confidence at speed

### For Driving Adoption

When you need to bring others along:

1. **Switch** — Change mechanics that actually work
2. **Influence** — Landing FOE with stakeholders
3. **Nudge** — Designing choice architecture
4. **Start With Why** — Purpose as alignment

### For Building Resilience

Making systems (and teams) antifragile:

1. **Antifragile** — Design for volatility
2. **Extreme Ownership** — Removing coordination drag
3. **Thinking, Fast and Slow** — Designing for human bias
