# Enabling Team

<ExternalMethodHeader />

## Why This Matters for Agentic Coding

Enabling teams help stream-aligned teams overcome obstacles and build capabilities. AI-assisted development is a new capability that most teams need help adopting effectively. Enabling teams can accelerate AI adoption organization-wide.

**The AI Capability Gap:**
- AI coding assistants are new to most developers
- Effective patterns aren't yet widely known
- Teams struggle to distinguish good from bad AI output
- Tool configuration and integration requires expertise

**Enabling Team Opportunity:**
- Help teams learn AI collaboration patterns
- Share what works across the organization
- Build institutional knowledge about AI effectiveness

## Adaptations for Agentic Coding

### AI Adoption Enablement

An enabling team focused on agentic coding might:

| Activity | Description |
|----------|-------------|
| Pairing sessions | Work alongside teams using AI tools |
| Pattern sharing | Document and teach effective prompting patterns |
| Tool evaluation | Assess AI tools and recommend standards |
| Metrics guidance | Help teams measure AI effectiveness |

### Temporary Engagement Model

Following the Team Topologies pattern:
1. **Identify teams** struggling with AI adoption or generating unreliable output
2. **Engage temporarily** to build their AI collaboration capabilities
3. **Transfer knowledge** through pairing, documentation, and training
4. **Disengage** when the team is self-sufficient

### What Enabling Teams Should NOT Do

- Become an "AI gateway" that creates dependencies
- Review all AI-generated code (creates bottleneck)
- Mandate specific AI tools or prompts (reduces autonomy)
- Stay permanently embedded (should build capability, then leave)

## Enabling Activities for AI

### Prompt Engineering Support

Help teams develop effective prompting:
- Review and improve team prompts
- Share successful patterns from other teams
- Create prompt templates for common tasks

### Verification Skill Building

Help teams catch AI errors:
- Train on common AI failure modes
- Build verification habits and checklists
- Set up automated verification infrastructure

### Tool Integration

Help with AI tool setup:
- IDE integration and configuration
- Custom instructions and context
- Connection to existing CI/CD
