# Field Guides

Field Guides are curated collections of **methods** - practical approaches to solving specific engineering challenges. Each method is backed by **experiments** - documented evidence from real-world application.

## How It Works

```
Field Guide
    └── Methods (practices you can adopt)
            └── Experiments (evidence that supports the method)
```

**Methods** progress through maturity levels as they accumulate supporting evidence:

| Level | Meaning |
|-------|---------|
| **Hypothesized** | Proposed approach, not yet tested |
| **Experimenting** | Active experiments underway |
| **Validated** | Supporting evidence exists |
| **Proven** | Multiple experiments confirm effectiveness |

A guide's overall maturity is the average of its methods - giving you a quick sense of how battle-tested the guidance is.
