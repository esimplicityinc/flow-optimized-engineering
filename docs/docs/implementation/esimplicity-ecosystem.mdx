## Key Insights

### KATALYST is the Gravitational Center

Everything ultimately runs on or connects to **KATALYST**. It provides:
- The infrastructure platform (Kubernetes, ArgoCD, observability)
- The taxonomy framework (architecture-as-code)
- The foundation that PRIMA and other systems build upon

[Learn more about KATALYST →](/docs/katalyst/overview)

### FOE is the Governing Ontology

**Flow Optimized Engineering** provides the conceptual framework that everything aligns to:
- The **Technical Review Board** ensures alignment to FOE principles
- The **Maturity Model** assesses organizational capability
- The **Engineering Field Guides** provide evidence-backed practices

[Learn more about FOE →](/docs/intro/what-is-foe)

### PRIMA is the Productized Surface

**PRIMA** is what government delivery teams interact with directly:
- **Control Tower** - Operational visibility
- **Web** - User interfaces
- **Code** - Application logic
- **Engine** - Processing capabilities

PRIMA runs on KATALYST, inheriting its infrastructure capabilities while providing a focused experience for government programs.

### Teams Bridge Strategy and Execution

| Team | Role |
|------|------|
| **Gov Delivery Teams** | Use PRIMA through Shine, assessed by TRB |
| **Technical Review Board** | Ensures alignment to FOE principles |
| **RIC Team 1 (Prima)** | Builds and maintains PRIMA |
| **RIC Team 2 (Katalyst)** | Develops KATALYST platform |
| **RIC Team 3 (Aaron)** | Bridges BD needs with platform reality |

### Shine: The Practice Lens

**Shine** is how government delivery teams see their work. It:
- Surfaces **Practices** for daily operations
- Runs on **KATALYST** infrastructure
- Provides visibility without exposing underlying complexity

## Relationship Types

| Relationship | Meaning |
|--------------|---------|
| **Builds** | Team is responsible for creating/maintaining |
| **Runs on** | System depends on platform infrastructure |
| **Uses** | Team or system utilizes capabilities |
| **Align to** | Governance ensures conformance |
| **Contains** | Parent includes child components |
| **Enables** | Framework makes platform possible |
| **Assessed by** | Governance body reviews |

## How This Maps to FOE Principles

The ecosystem embodies FOE's three core optimizations:

### Optimize for Understanding
- **KATALYST Taxonomy** provides architecture-as-code
- **Shine** surfaces practices in understandable form
- **Field Guides** document evidence-backed approaches

### Optimize for Fast Feedback
- **KATALYST BDD Test** enables multi-layer testing
- **Technical Review Board** provides governance feedback
- **RIC Teams** iterate rapidly on platforms

### Optimize for Confidence
- **KATALYST Platform** provides GitOps deployment
- **PRIMA** inherits infrastructure confidence
- **Maturity Model** tracks organizational progress
